CSS RULES:
- Define ALL design token values as CSS custom properties in :root
- Use var(--token-name) everywhere, never hardcoded values
- Each section: <section class="uw-section uw-{section_id}" id="{section_id}">
- Container: <div class="uw-container"> with max-width from design_tokens
- Flexbox or CSS Grid for layouts — no floats, no tables for layout
- Transitions on all interactive elements: transition: all 0.2s ease
- Hover + focus states on all buttons and links
- Mobile-first responsive: default styles for mobile, @media min-width: 768px for desktop

Add a small <script> at the end of <body> for the accordion toggle:
<script>
document.querySelectorAll('.uw-accordion__trigger').forEach(btn => {
  btn.addEventListener('click', () => {
    const expanded = btn.getAttribute('aria-expanded') === 'true';
    btn.setAttribute('aria-expanded', !expanded);
    btn.nextElementSibling.hidden = expanded;
  });
});
</script>
