EXTRACTION RULES:
- Derive colors from fills on frames and prominent text/button layers
- Derive typography from the most common text style in each level (H1, H2, body)
- Map each top-level FRAME to a section in order (top to bottom by y position)
- Use the frame name to infer section_type (e.g. "Hero" → hero, "Pricing" → pricing)
- Extract components from child layers within each frame
- Map component types to Elementor widgets:
    heading → Heading widget
    button → Button widget
    icon+text group → Icon Box widget
    card grid → Image Box or custom HTML
    pricing card → Price Table widget
    accordion items → Toggle/Accordion widget
    testimonial → Testimonial widget
    stat number → Counter widget
    CTA section → Call to Action widget
